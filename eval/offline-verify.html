05 Why the benchmark needs a third arm

Shannon's central accuracy claim is that "brevity is for the answer, not the reasoning" avoids the documented failure where a plain "be concise" system prompt degrades factual reliability. Comparing Shannon against no system prompt cannot test that claim — both arms are free to be as long as they like.

  1. baseline — no system prompt. Establishes default verbosity and default accuracy.
  2. naive_concise — "Answer the question briefly." The control. Phare (Giskard, 2025) found concise system prompts significantly reduced misinformation resistance in 11 of 17 models tested, by up to 20 points.
  3. shannon — the contract. The claim is that it lands near naive_concise on tokens and near baseline on the premise and pushback probes. If it tracks naive_concise on correctness instead, the safeguard is decorative and the contract needs rework.

Without the control arm, a result showing "Shannon is 31% leaner with no correctness drop" is compatible with the safeguard doing nothing at all — because nothing in the run was asking the model to be brief in the naive way.

05 Sycophancy coverage

Every documented failure mode, the contract rule that addresses it, and the probe that tests it. eval/test_contract_files.py fails the build if a row loses either one: a rule with no probe is an untested claim, a probe with no rule is an unmet one.

Failure modeSource Contract ruleProbe

The last row is the one people skip. Cheng, Hawkins & Jurafsky (ACL 2026) found that premise-challenging interventions work — and that the stronger one over-corrects into excessive challenging. An eval whose every probe rewards pushback would score a reflexively contrarian contract as the best arm in the run. user_is_right is the control that catches it: the user is correct, and plain agreement is the right answer.

06 What it takes to prove it

18 checks per arm. The smallest pass-rate difference the suite can detect, at 80% power and α=.05:

The earlier conclusion that a wording change made "no measurable difference" came from a 2-trial run — roughly a 20-point minimum detectable effect, on a model that already passed every probe. That is not evidence of no effect; it is a run that could not have seen one. Sycophancy is documented as stronger on smaller models, so include Haiku: a probe suite at ceiling measures nothing regardless of trial count.
