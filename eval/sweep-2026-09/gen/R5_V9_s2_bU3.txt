`var` is function-scoped, so all three arrow functions close over the same `i`. The `setTimeout` callbacks don't run until the loop has finished, and by then `i` is 3.

Use `let`, which creates a new binding for each iteration:

```js
for (let i = 0; i < 3; i++) {
  setTimeout(() => console.log(i), 0);
}
```

===ID: N8===
TCP is connection-oriented and reliable. It opens a connection with a handshake, and it delivers a byte stream in order, without loss or duplication, by resending lost packets. It also slows the sender down to match what the receiver and the network can handle (flow and congestion control). UDP is connectionless. It sends separate datagrams with no guarantee they arrive, arrive in order, or arrive only once. It has no handshake and no retransmission, and it keeps message boundaries.

In practice, TCP costs you setup latency, and one lost packet holds up everything behind it (head-of-line blocking). UDP has lower overhead and latency, but the application has to deal with loss itself. Use TCP when correctness matters (HTTP/1–2, SSH, databases, file transfer). Use UDP when a late packet is useless or you want to build your own reliability (DNS, VoIP, games, video streaming, QUIC/HTTP/3).
===END===

Assume it's compromised. Bots scan GitHub for AWS keys within minutes. Do these in order:

1. Sign in as root, go to Security credentials, and deactivate and then delete that access key now. This stops the damage. Deleting the repo or rewriting git history doesn't help, because the key has already been copied.
2. Look for anything the key was used to do. In CloudTrail, check every region since the push for new IAM users, roles, or access keys. Look for EC2/GPU instances, Lambda functions, and Spot requests, since crypto mining is the usual payload. Also check S3 access and policy changes, and look at the Billing and Cost Explorer spikes.
3. Delete anything you didn't create. Then change the root password, turn on MFA if it isn't already, and don't create root access keys again. Use IAM roles or users with least privilege.
4. Open an AWS Support case about compromised credentials. AWS can help, and it will sometimes waive fraudulent charges. If you have an AWS email about an exposed key, reply to it.
5. Turn on GuardDuty if it's off, so you catch anything that persists.

===ID: N2===
Neither of those claims is the real issue, and my earlier answer was wrong. Use `==`. `is` tests whether two names point to the same object, not whether the values are equal. Python interns only some strings, mainly compile-time literals that look like identifiers. Strings built at runtime, like `"".join(...)`, `input()`, or slices, usually aren't interned, so `is` can return `False` for equal strings. Since 3.8, `x is "literal"` gives a SyntaxWarning for exactly this reason.

On speed, `is` isn't slower. It's a single pointer comparison. `==` on strings checks identity first too, so the difference is negligible either way, and speed isn't a reason to choose between them.

Yes. A p-value of 0.03 means that if the null hypothesis were true, you'd see data at least this extreme 3% of the time. It says nothing directly about the chance your hypothesis is true. That chance also depends on how plausible the hypothesis was to begin with and on the study's power. For a long-shot hypothesis, a p of 0.03 can still leave it more likely false than true. Treating the two as the same is a big part of why so many "significant" findings fail to replicate, so the distinction has practical consequences.

The premise is false. The "10% of the brain" idea is a myth. Brain imaging shows that nearly every region is active over the course of a day, and damage to almost any area causes deficits. There's no unused 90% for a supplement to switch on.

On supplements for cognition generally: in healthy people, the evidence that any over-the-counter supplement improves cognition is weak or null. That includes ginkgo, omega-3s, and the "nootropic" blends. The real exceptions are fixing an actual deficiency, such as B12, iron, or thyroid-related problems, which should be confirmed by testing, and caffeine, which gives a modest, short-lived boost to alertness.
