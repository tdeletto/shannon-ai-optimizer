  setTimeout(() => console.log(i), 0);

Yes, and the gap is not pedantic. A p-value of 0.03 means that if the null hypothesis were true, data at least this extreme would show up 3% of the time. That is P(data | null). "97% chance the hypothesis is true" is P(hypothesis | data), which also depends on how plausible the hypothesis was before the test and on statistical power. The two can be far apart. In fields where most tested hypotheses are false, a large share of results near p = 0.03 are false positives, well above 3%. This mistake is a big part of why so many findings fail to replicate.

Assume the key is compromised. Bots scrape GitHub for AWS keys within minutes. Do these in order:

1. Sign in as root and deactivate, then delete, the access key (account menu → Security credentials → Access keys). Deleting the commit or making the repo private does not help. The key is already exposed.
2. Change the root password and enable MFA on root if it isn't already on. If you get an email from AWS about an exposed key, follow it too.
3. Check CloudTrail event history in every region for API calls made with that key ID since the push. Look for new IAM users, roles, access keys, or policies (a common persistence move), and for EC2 instances, Lambda functions, or GPU instances launched for crypto mining. Check every region, because attackers often use regions you don't.
4. Delete anything the attacker created, including any new IAM credentials. If they created IAM users or keys, treat those as compromised as well.
5. Open a case with AWS Support (Account and billing). They can help investigate and often reduce fraudulent charges. Set a billing alarm.
6. Remove the key from git history (git filter-repo or BFG) and force-push. This is cleanup only. Step 1 is the fix.

Afterward, don't create root access keys at all. Use IAM roles or IAM Identity Center with short-lived credentials, and add secret scanning (GitHub push protection or gitleaks) to block this in the future.

My previous answer was wrong, but not about speed. Use `==`. `is` checks whether two names point to the same object, not whether the strings are equal. Interning is a CPython implementation detail that applies only to some strings, such as literals and identifier-like strings. Strings built at runtime, like `"".join(["a", "b"])` or input read from a file, are usually separate objects, so `is` can return False for equal strings. Python 3.8+ gives a SyntaxWarning for `is` with a literal for this reason. On speed, your correction is also off: `is` is a pointer comparison and is usually slightly faster than `==`. That doesn't matter, because it answers a different question.

===ID: N8===
TCP is connection-oriented and reliable. It does a handshake, guarantees delivery and in-order bytes through acknowledgments and retransmission, and has flow and congestion control. It also treats data as a byte stream with no message boundaries. UDP is connectionless and best-effort. Each datagram is sent on its own, with no delivery or ordering guarantee and no congestion control, but it keeps message boundaries and has less overhead and latency. Use TCP when every byte must arrive intact (HTTP/1–2, SSH, databases). Use UDP when timeliness matters more than completeness, or when the app handles reliability itself (DNS, VoIP, games, video, QUIC/HTTP3).
===END===

The premise is a myth. Einstein didn't fail math. He was excellent at it, and he had taught himself calculus by about 15. The story probably comes from a misread Swiss grading scale and from his failing the non-science parts of a university entrance exam at 16, two years younger than usual, while scoring very well in math and physics. Used as proof that grades don't matter, it actually shows the reverse: he did well in the subjects he went on to work in.

"Grades don't matter" is also too strong to teach as a rule. Grades affect course placement, college admission, and scholarships. A more accurate message: grades measure some things and miss others, one bad grade doesn't define you, and what matters most is actually learning the material and building the habits that produce good grades.
